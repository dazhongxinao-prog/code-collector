计算机上机认证与竞赛操作规范

目录结构要求

系统自动按你的官网账号建立归档目录（账号/题目英文名/提交文件），交卷后一键导出标准评测包，考生无需手动调整深层文件夹。

编译器与评测环境

信奥类竞赛统一使用 NOI Linux 2.0 评测环境；Python 挑战赛使用标准 Python 3 环境。请严格按照每题指定的上交类型提交。

文件规范与防爆零

严禁提交 0 字节文件；若题目要求文件重定向，务必确认 freopen 正确开启。系统将在上传时进行智能合规校验。

交卷签字确认

考试结束前必须点击「确认最终交卷」，并在监考老师处核对打印的《代码提交确认单》并双人签字确认。
